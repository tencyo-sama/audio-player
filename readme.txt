# ギターの練習するやつ (Web Audio/Video Player)

このプロジェクトは、YouTubeなどの動画をダウンロードして、ギター練習用に特化したWebプレイヤー（GitHub Pages等で動作）で再生するためのシステムです。動画の再生速度（テンポ）と音程（ピッチ）を完全に独立して調整でき、映像と音声のズレ（A/V Sync）を極限まで抑える独自の同期ロジックを搭載しています。

## 🎸 プレイヤーの主な機能
- **独立したテンポ・ピッチ制御 (SoundTouch.js使用)**
  - テンポ: 50% 〜 120% (5%刻みでボタン操作)
  - ピッチ: -4 〜 +4 半音 (1半音刻みでボタン操作)
- **強力なA/V同期**
  - 音声をマスタークロックとし、映像の再生位置を自動補正（パフォーマンス優先のスタッタリング対策済み）
- **A-Bループ機能**
  - 練習したい特定区間をシームレスに繰り返し再生
- **モバイル・PC対応フルスクリーン**
  - フルスクリーン展開時、スマホの自動回転設定に依存せず「横向き(Landscape)」に強制ロック
  - 動画画面のタップで再生/一時停止の直感的な切り替え
- **動画リストの自動読み込み**
  - 追加した動画はプルダウンから一発でロード可能

## 📥 動画の追加方法 (Pythonスクリプトによる自動化)

Pythonスクリプト (`main.py`) を使用して、指定したURLの動画をダウンロードし、GitHubリポジトリに同期します。
※前提要件: `uv`（Pythonパッケージマネージャー）と `git` がインストールされていること。

**手順:**
1. プロジェクトのルートディレクトリ (`/home/u0715/projects/audio-player`) を開きます。
2. 以下のコマンドを実行して、動画をダウンロード＆デプロイします。

```bash
uv run python main.py "[YouTubeなどの動画URL]"
```

**仕様と注意点:**
- GitHubのファイルサイズ制限(100MB)を回避するため、内部で**95MB以下かつ解像度720p以下**の動画を自動選択してダウンロードします。
- スクリプトが完了すると、`videos/` フォルダに動画が保存され、`video_list.json` が更新された後、**自動的に git commit と git push が実行されます**。
- Push後、数分でGitHub Pages環境に変更が反映され、Webプレイヤーのリストから新しい動画が選択可能になります。
